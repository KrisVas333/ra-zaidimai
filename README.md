# RA žaidimai (Robotikos Akademijos žaidimai)

Short browser games for kids from Robotikos Akademija. First game: **Roboto ranka** (`/roboto-ranka/`), a lesson where a child builds a robot arm.

- **Experimental.** An AI-assisted prototype. It can be wrong, and it is still being tested.
- **Free.** No account, no ads.
- **Anonymous feedback.** Tap the ⭐ to rate it. No names, no cookies, no session recordings.
- **Contact:** [krisvas.lt](https://krisvas.lt)

Played in the browser, nothing to install. More games will land here.
